### 📜 Шпаргалка по командам Go

| Команда | Что делает | Зачем нужно |
|--------|------------|-------------|
| `go mod init <имя-модуля>` | Инициализирует новый Go-модуль | Создаёт `go.mod` и `go.sum` при начале нового проекта |
| `go mod tidy` | Синхронизирует зависимости в `go.mod` и `go.sum` | Добавляет используемые, удаляет неиспользуемые зависимости |
| `go run <файл>.go` | Компилирует и запускает один Go-файл | Быстро протестировать код или запустить программу |
| `go run .` | Компилирует и запускает весь пакет в текущей директории | Запустить основное приложение (там, где `main`) |
| `go build` | Компилирует код в исполняемый файл | Создаёт бинарный файл, который можно запустить позже |
| `go build .` | Компилирует проект в текущей папке | Создаёт исполняемый файл проекта |
| `go test` | Запускает тесты в текущей папке | Проверить, работает ли код как ожидается |
| `go test -v` | Запускает тесты с подробным выводом | Удобно, чтобы видеть, какие тесты прошли, какие нет |
| `go test ./...` | Запускает все тесты во всех подпапках | Проверить весь проект целиком |
| `go vet` | Проверяет код на потенциальные ошибки | Помогает найти логические и стилистические проблемы |
| `gofmt -w .` | Форматирует все Go-файлы в текущей папке | Приводит код к единому стилю |
| `go doc <имя-пакета>` | Показывает документацию к пакету | Узнать, что делают функции и структуры в пакете |
| `go list -m all` | Показывает список всех зависимостей | Посмотреть, какие библиотеки использует проект |
| `go clean -modcache` | Очищает кэш зависимостей | Полезно, если что-то пошло не так с загрузкой библиотек |
